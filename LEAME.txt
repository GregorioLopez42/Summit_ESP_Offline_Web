SUMMIT ESP OFFLINE WEB - PWA FINAL

PUBLICACION
Suba todos los archivos y la carpeta icons al nivel principal del repositorio GitHub Pages. La URL debe usar HTTPS.

ANDROID
Abra la URL en Chrome o Edge. Use el botón Instalar. Después de instalar, abra Summit ESP desde el icono; el banner de instalación ya no aparecerá.

iPHONE / iPAD
Abra la URL en Safari. La aplicación mostrará una guía: Share, Add to Home Screen, Add. Después abra Summit ESP desde el icono; la guía ya no aparecerá dentro de la aplicación instalada.

ACTUALIZACION
El service worker utiliza una nueva versión de caché y elimina cachés anteriores al activarse.
